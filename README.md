# CamPrompt project page

Source for the CamPrompt (WACV 2027) project page, served with GitHub Pages.

* `index.html` - the page
* `static/` - styles, scripts, figures and result videos
* `data/` - the released annotation files (`camprompt_annotations_v1.zip`), dataset card, license and checksums

Website template adapted from [Nerfies](https://github.com/nerfies/nerfies.github.io)
(CC BY-SA 4.0). The annotation files in `data/` are licensed under CC BY 4.0 (see `data/LICENSE`).
